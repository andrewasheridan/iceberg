# Cases

The [`cases/`](https://github.com/andrewasheridan/iceberg/tree/main/cases) directory
of the repository has one small example package for each layout and edge case that
iceberg supports. Each case page shows the command, the expected output and an
explanation of the output.

The cases are also golden tests. The tests run each command in a case README and
compare the output with the README. Thus, the output on these pages is the output of
the current version of iceberg.

Select a case in the navigation to see it.
